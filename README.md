# 科研训练（Research Training）

## 仓库用途
本仓库用于管理「科研训练」课程的全过程产出，围绕论文阅读、方法分析、问题构建、答案沉淀与研究计划设计，形成可追踪、可复用的科研学习档案。

## 课程流程
课程按以下固定链路推进：

1. **论文解读**：准确理解研究问题、数据、方法与结论。
2. **深度分析**：拆解模型机制、实验设计、假设与可复现性。
3. **出题90**：围绕论文设计 90 个高质量问题（9 类 × 每类 10 题）。
4. **回答问题**：基于证据作答，区分事实、理解与不确定性。
5. **做研究计划**：基于原论文缺口提出可执行的小型研究方案。

## 工作规范
- 所有输出使用 Markdown，结构化记录，避免口语化堆叠。
- 每条关键结论需标注来源依据（论文图表、正文段落、补充材料）。
- 问题设计应覆盖背景、方法、实验、解释性、局限与扩展。
- 回答应区分：论文事实 / 个人理解 / 未解决疑问。
- 每周至少完成一次日志更新，保证迭代连续性。

## 每周推进方式
建议以周为单位执行固定节奏：

- **周初**：设定本周目标与交付物。
- **周中**：推进阅读、分析、问题构建与实验设想。
- **周末**：总结完成情况、问题阻塞、下周计划与反思。

建议在 `weekly_logs/` 维护周报，在 `papers/DeepGxP/` 持续更新论文相关核心文档。
